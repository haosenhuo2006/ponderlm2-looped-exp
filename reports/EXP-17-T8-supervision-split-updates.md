# EXP-17 — T8：汇总中间监督 + 拆分更新

## 0. 为什么这个实验有必要做

补齐监督与更新次数的 2×2 对照；“无监督”在这里指无中间监督，仍监督最终预测。

| 中间监督 | 600 次更新 | 1494 次更新 |
|---|---|---|
| 无 | T1：6.01 | T7：5.52 |
| 有（汇总式、无 detach） | T5：5.84 | T8：? |

另有 T6（每轮监督 + 逐轮更新 + detach，1494 次更新）：5.19。
T8−T7 隔离“监督”（更新次数固定 1494、无 detach）；
T6−T8 隔离“逐轮更新 + detach”（监督形式固定为每轮 CE；反向聚合方式的细微差别见 §4）。

第三阶段认为这个拆分“边际信息不大”，是因为当时要决定追规模还是回机制，
拆分结果不改变选择。现在方向已定为回机制，结果直接决定下一项机制实验：
往监督信号做深（轮次加权、辅助损失），还是往更新节奏做深（频率、截断方式）。
已有 T1/T5/T6/T7 终点和曲线无法替代缺失的 T8 单元；只增加训练步数会混入 token
预算，不能回答这个问题。因此选择固定 token 预算的组合对照。

判定逻辑（跑之前写清）：
- T8 ≈ T6 → 监督本身解释了剩下的 41%，逐轮更新 + 截断不重要。
- T8 ≈ T7 → 监督本身几乎无贡献，剩下的 41% 来自逐轮更新 + 截断。
- T8 在中间 → 两者各贡献一部分，按 T8−T7 与 T6−T8 的大小分解。

这里的近似是终点机制解释，单种子不能给出统计等价结论；41% 是历史点估计。

## 1. 方法

T8 配置以 EXP-01-T1 为基线，只改 run_dir，打开 split_optimizer_updates 和
intermediate_supervision；满训练仍为 600 数据步。每数据步相同的 16 个 microbatch，
seq 256，独立 random.Random(42) 抽取 K∈{2,3}。相同 K 序列应含 306 个 2、
294 个 3，共 1494 次优化器更新；总输入 tokens 不变。

split_groups 连续切分：K=2 为 8+8，K=3 为 6+5+5。每组开始 zero_grad；
组内每个 microbatch 调用 T5 式 masked_forward，D0 可见性，K 轮 refinement CE
取均值。token-only 初始化不监督，单独 final pass 仅监测、不作为第 K+1 项损失。
每个 microbatch 按 (loss/16).backward() 累积，分母始终是总 microbatch 数。
每组累积完只 clip 一次、step 一次。组内轮间不 detach，保留完整 T5 图；
组间更新参数后重新前向，不复用旧图。

梯度等价口径仅在固定参数、禁用 step/zero_grad/clip 的条件下成立：
K 组梯度之和与直接按 T5 式累加全部 16 个 microbatch 一致。
GPU 测试对 K=2/3 均使用相同 bf16 autocast，逐参数 atol=1e-6、rtol=0；
另检查 loss 是各轮 CE 均值的再平均、最终 CE、更新计数、参数变化与有限性。
实际执行中参数在组间变化，不能把这个测试解释为与单次 T5 更新轨迹等价。

AdamW 和 LR 公式沿用 T1：LR 按数据步索引，同一步 K 次更新共用 lr，
warmup 20、峰值 1e-4、cosine 到 1e-5。每组 clip，日志 grad_norm 为各组
clip 前 norm 最大值。checkpoint、数据顺序与 60 分钟预算机制沿用现有实现。
100 步 pilot 配置只再改 steps/run_dir；其 cosine 在 100 步结束，属于稳定性门，
不是满训练 step-100 的同 schedule 对照。门检查有限性、loss 不发散、梯度中位数
相对 T1+T5 前 100 步在 0.1–10 倍内，以及前 1600 个数据索引一致。

评测已全部执行：pilot 通过后跑满训练，使用 step-600 checkpoint、
--mode ponder、validation，固定 977 chunk、249135 targets。
随后按 EXP-07 相同诊断流程补跑了 src.evaluate_rounds（T8 和 T1）及
src.jacobi_check（见 §2）。
run_exp17.sh 按 EXP-13 结构负责满训练、主评测与汇总；附加诊断由收尾协调员随后运行。
汇总校验 600 有序步骤、K 序列和累计更新、完整数据顺序、源文件 SHA256、
评测有限性及 PPL=exp(NLL)、完成标志；读取 T1/T5/T6/T7 的历史评测作对照。

## 2. 结果

### 2.1 Pilot 决策门：通过，继续满训

100 步，244 次更新，全部有限、无发散、无 OOM，数据顺序前缀与 T1 一致。
梯度中位数 24.92，相对 T1/T5 前 100 步基线 36.39 的比值 0.685（在 0.1–10 门内）；
最大梯度 137.36；前 20 步均值 CE 10.05 → 后 20 步 7.57；wall 198.6 s。
Pilot 的 100 步 cosine 与满训不同，只是稳定性门。

### 2.2 满训：600 步一次成功

attempt 1 exit 0，无重试。600 数据步，1494 次优化器更新，
K 序列 306 个 2、294 个 3（与设计一致）；总输入 tokens 2,457,600；
wall 828.9 s，峰值 allocated 1821.5 MiB。

训练 loss（每 100 步均值；final CE 与 loss 几乎相同）：

| step | mean loss | mean final CE |
|---|---|---|
| 1–100 | 8.453 | 8.464 |
| 101–200 | 6.237 | 6.237 |
| 201–300 | 5.341 | 5.344 |
| 301–400 | 5.102 | 5.103 |
| 401–500 | 4.936 | 4.936 |
| 501–600 | 4.833 | 4.833 |

末段仍在下降（501–600 步均值 4.83，step 600 当步 final CE 4.53），
训练 CE 没有触顶。

### 2.3 主验证：T8 = 4.9944，2×2 补齐

step-600 checkpoint，--mode ponder，validation，977 chunk、249135 targets：

| 模型 | 主验证 NLL | PPL |
|---|---|---|
| T0（vanilla，600 步） | 4.9271 | 137.98 |
| T1（无监督，600 次更新） | 6.0070 | 406.25 |
| T5（汇总监督，600 次更新） | 5.8356 | 342.29 |
| T7（无监督，1494 次更新） | 5.5237 | 251.07 |
| **T8（汇总监督，1494 次更新）** | **4.9944** | **147.58** |
| T6（每轮监督 + 逐轮更新 + detach，1494 次更新） | 5.1903 | 179.52 |

实测 NLL 4.994362933984006，PPL 147.57889792888665，评测 39.7 s。

分解（ΔNLL，单种子点估计）：

| 对比 | ΔNLL | 解释 |
|---|---|---|
| T7−T1 | −0.4833 | 无监督时，更新次数 600→1494 的效应 |
| T5−T1 | −0.1713 | 600 次更新时，汇总监督的效应 |
| T8−T7 | −0.5293 | 1494 次更新时，汇总监督的效应 |
| T8−T5 | −0.8413 | 有监督时，更新次数 600→1494 的效应 |
| T8−T1 | −1.0126 | 两因素合计 |
| T8−T6 | −0.1959 | T8 好于 T6 |
| T8−T0 | +0.0673 | 距 vanilla 只差 0.067 |

两因素单独效应之和是 −0.4833 + −0.1713 = −0.6546，小于合计 −1.0126：
监督与更新次数存在约 −0.36 的正交互——监督在更新频繁时帮助更大
（−0.5293 vs −0.1713），更新次数在有监督时帮助也更大（−0.8413 vs −0.4833）。

### 2.4 逐轮 NLL：平坦，首轮最好

| k | T8 | T1（重算） |
|---|---|---|
| 1 | 4.99102 | 6.14484 |
| 2 | 4.99420 | 6.00697 |
| 3 | 4.99440 | 6.00783 |

T8 的第 1 轮就是最低（比 final 好 0.0034），轮间几乎无递进；
T1 重算的逐轮数字与 EXP-01 逐位一致。结论与 PROBE-2 一致：
精炼轮次不是杠杆。

## 3. 结论

1. **2×2 补齐了，监督与更新次数是超加性的。** T8（4.9944）比 T7（5.5237）
   好 0.5293、比 T5（5.8356）好 0.8413、比 T1（6.0070）好 1.0126。
   两因素单独效应之和（−0.6546）解释不了合计，交互约 −0.36。
   监督不是“有就行”的小幅加成：在更新频繁时它的收益是原来的三倍。
2. **§0 的判定逻辑三种情形都没出现——T8 比 T6 和 T7 都好。**
   T8 比 T6 好 0.1959。这修正了 EXP-13 的分解：剩下的 41% 不必归于
   “每轮监督 + 截断”——汇总式中间监督本身（无 detach、均值后一次反向）
   已经能解释甚至超过这部分；逐轮更新 + detach 不是必需的，甚至可能
   略拖后腿。但必须同时说清：T6 与 T8 还差在 clip 口径上（T6 每轮 clip，
   T8 每组 clip），0.1959 不宜解读为纯 detach 效应；单种子，也不能
   断言显著。
3. **T8 是 600 步预算下最好的 ponder 变体，距 vanilla 只差 0.067。**
   T8−T0 = +0.0673（4.9944 vs 4.9271）。但 T6×1200（4.8870）仍然更好，
   说明更新次数 × 步数的复合仍有余量，600 步不是 T8 的天花板。
4. **逐轮精炼与 Jacobi 收敛都不是 T8 好结果的来源。** 逐轮 NLL 平坦、
   首轮最好；d_8 = 0.082 未紧收敛。好结果来自训练目标与更新节奏，
   不是推理时多算几轮。
5. **下一步建议（按 §0 的逻辑）：往监督信号做深，优先于往更新节奏做深。**
   具体候选：T8×1200 步（T8 在 600 步已接近 T0，1200 步可能打平甚至
   超过 T0×1200 的 4.7428）；监督信号的深化（轮次加权、辅助损失）。
   未做项：T8 > T6 的多种子配对验证（0.1959 需复核后才能当作结论用），
   以及 T8 的下游 benchmark。

## 4. 残留混杂与局限

- 每组单独 clip，T1 每数据步只 clip 一次。
- 小 batch 梯度噪声是“更频繁更新”机制的一部分；Adam 状态和 weight decay 的累计次数也随更新次数变化。
- T6 与 T8 的监督形式有细微差别：T6 是每轮 CE 各自反向，T8 是均值后一次反向（每个 microbatch）。这是“逐轮更新”机制定义的一部分；T6−T8 不宜解读为纯 detach 效应。
- 单种子、WikiText-2、70M tiny-scale，无下游泛化或规模结论。历史占比分解与近似判定不等于显著性检验。
